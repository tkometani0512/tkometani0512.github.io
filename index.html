$02 — Featured Project

Real-Time FPGA Camera-to-VGA Video Pipeline

Processorless OV7670 video capture and display on a Nexys A7-100T FPGA.

[ADD IMAGE: hardware bench photo — IMG_5264.png / IMG_5276.png]
VHDL Xilinx Vivado Nexys A7-100T OV7670 Dual-Port BRAM SCCB / I2C

Live camera feed, captured and displayed entirely in FPGA logic

No processor in the data path — capture, buffering, scaling, and display all run in programmable logic.

Designed and implemented a real-time video pipeline on a Nexys A7-100T FPGA that configures an OV7670 camera over SCCB/I2C, reconstructs incoming pixel data into 12-bit RGB, stores complete 320×240 frames in dual-port Block RAM, and renders a scaled, centered VGA output at 800×600 — all without a processor in the pipeline.

Source resolution320 × 240 (QVGA)
Display output800 × 600 @ 60 Hz VGA
Frame buffer76,800 px · 12-bit RGB · dual-port BRAM
Camera clock (XCLK)~24 MHz
Capture control3-state FSM (WAIT_VSYNC / WAIT_HREF / CAPTURE)
User controlsFreeze frame (SW0) · Color invert (SW1)
Team context — this was a two-person course project (CPE 487, Spring 2026, Prof. Byett).
  • Tyler Kometani: VHDL development, FPGA architecture, hardware implementation, integration, and debugging
  • Bryan Barzola: documentation and poster development
